# Alpine Linux 向け IPv4-to-IPv6 プロキシ

[Tiếng Việt](README.md) | [简体中文](README.zh-CN.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [English](README.en.md)

このインストーラーは **Alpine Linux 専用**で、3proxy 1.0.3 と OpenRC を使用します。1 つのパブリック IPv4 アドレスの複数ポートで HTTP プロキシ接続を受け付け、各ポートは異なる IPv6 アドレスを外向き接続に使用します。IPv6 アドレスは、プロバイダーが VPS にルーティングする /64 サブネットから割り当てます。プロキシプール全体で 1 組のユーザー名とパスワードを共有します。

## インストール

必要条件：Alpine 上の root 権限、VPS に直接割り当てられたパブリック IPv4 アドレス、利用可能な IPv6 接続、VPS にルーティングされる IPv6 /64 サブネット。インストール前にプロバイダーの管理画面で IPv6 を有効にしてください。

[`setup-alpine.sh`](setup-alpine.sh) を VPS にコピーし、スクリプトを確認してから実行します。

```sh
sh setup-alpine.sh --count 2000
```

スクリプトは TTY を通じてユーザー名とパスワードの入力を求めます。実際のアカウント情報やサーバーの IP アドレスは埋め込まれていません。デフォルトでは 10000 から 11999 のポートに 2,000 個のプロキシを作成します。インストール後の運用にも使用するため、バンドルされたスクリプトを保管してください。

## よく使うコマンド

```sh
sh setup-alpine.sh --operation status
sh setup-alpine.sh --operation verify --sample 3
sh setup-alpine.sh --operation export --format csv --output /root/proxy-export.csv
```

運用コマンドでは `apk` の実行や 3proxy の再コンパイルは行いません。エクスポートファイルにはパスワードが含まれ、権限 `0600` で作成されます。自動アップロードは行いません。

## 実際の制約

- 宛先ポート 80/443 の HTTP/HTTPS 接続のみを許可します。プライベートアドレス、リンクローカルアドレス、プロキシプールやサーバーのネットワーク内への接続はブロックします。
- `maxconn=65535` はプロセスのファイルディスクリプター上限と一致しますが、65,535 本の同時接続を保証する値ではありません。`nproc` は無制限です。`connlim` による割り当て制限や、UFW による 512 接続の制限は設定しません。
- ローカルテストは、各 VPS でのルーティング、認証、別のマシンからの接続、再起動後の動作確認の代わりにはなりません。待ち受けポート数がそろっていても、スループットが実証されたことにはなりません。
